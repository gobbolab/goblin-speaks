# Components Overview

This page provides an overview of components which can be used to assemble your machine.
Components by Gobbo Lab are provided out of the box by the framework itself and are officially supported.

## Animatronic Bodies

These are the animatronic bodies available in the framework.
Use these as the base for an animated character in your machine.

| Name | Description | Author | Details |
|---|---|---|---|
| Goblin Speaks Body | A humanoid animatronic body which supports two SG-90 servo motors, the first for mouth movement and the second for moving a single arm. | Gobbo Lab | [View Details](goblin-speaks-animatronic-body.md) |

## Object Dispensers

These are the available object dispensers in the framework.
Use these to dispense fortune cards or other objects to players of the machine.

| Name | Description | Author | Details |
|---|---|---|---|
| Goblin Speaks Card Dispenser | A top loaded card dispenser which uses a small stepper motor to dispense cards. Capable of holding roughly one deck of standard poker sized playing cards. | Gobbo Lab | [View Details](goblin-speaks-card-dispenser.md) |

## Coin Readers

| Name | Description | Author | Details |
|---|---|---|---|
| Goblin Speaks Coin Reader | A dumb coin reader which uses IR light sensors to detect when something (hopefully a coin) comes down the chute. | Gobbo Lab | [View Details](goblin-speaks-coin-reader.md) |

## Heads

These are the available heads in the framework.
Mount these to your animatronic body to give your machine some character.

| Name | Description | Author | Details |
|---|---|---|---|
| Goblin Speaks Head | A goblin shaped head with an articulating mouth. Mounts easily to the Goblin Speaks Body and allows for mouth animation by connecting to a rod controlled by a servo in the body. | Gobbo Lab | [View Details](goblin-speaks-head.md) |
