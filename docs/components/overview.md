# Components Overview

This page provides an overview of officially supported components which can be used to assemble your machine.

## Animatronic Bodies

These are the animatronic bodies available in the framework.
Use these as the base for an animated character in your machine.

| Name | Description | Details |
|---|---|---|
| Goblin Speaks Body (Gobbo Lab) | A humanoid animatronic body which supports two SG-90 servo motors, the first for mouth movement and the second for moving a single arm. | [View Details](goblin-speaks-animatronic-body.md) |

## Object Dispensers

These are the available object dispensers in the framework.
Use these to dispense fortune cards or other objects to players of the machine.

| Name | Description | Details |
|---|---|---|
| Goblin Speaks Card Dispenser (Gobbo Lab) | A top loaded card dispenser which uses a small stepper motor to dispense cards. Capable of holding roughly one deck of standard poker sized playing cards. | [View Details](goblin-speaks-card-dispenser.md) |

## Coin Readers

| Name | Description | Details |
|---|---|---|
| Goblin Speaks Coin Reader (Gobbo Lab) | A dumb coin reader which uses IR light sensors to detect when something (hopefully a coin) comes down the chute. | [View Details](goblin-speaks-coin-reader.md) |

## Heads

These are the available heads in the framework.
Mount these to your animatronic body to give your fortune teller some character.

| Name | Description | Details |
|---|---|---|
| Goblin Speaks Head (Gobbo Lab) | A goblin shaped head with an articulating mouth. Mounts easily to the Goblin Speaks Body and allows for mouth animation by connecting to a rod controlled by a servo in the body. | [View Details](goblin-speaks-head.md) |
